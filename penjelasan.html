Apa itu PPLG?

Jurusan yang mempelajari cara merancang, membuat, menguji, dan mengembangkan perangkat lunak, aplikasi, website, dan gim. Menjadi kreator teknologi yang membangun solusi digital untuk masa depan!

Peluang Karir

  • Web Developer
  • Mobile Developer
  • Game Developer
  • UI/UX Designer
  • Data Analyst

FASE E (KELAS X)

Membangun Dasar, Mengenal Dunia Teknologi

1. Sistem Komputer

Memahami komponen komputer, sistem operasi, dan cara kerja komputer secara menyeluruh.

2. Jaringan Komputer Dasar

Memahami konsep dasar arsitektur jaringan lokal hingga internet dan konfigurasi sederhana.

3. Algoritma & Pemrograman

Membangun logika berpikir komputasional, pembuatan struktur flowchart, dan skrip kode dasar.

4. Basis Data Dasar

Mengenal konsep penyimpanan data terstruktur, pembuatan tabel relasional, dan query manipulasi data.

5. UI/UX Dasar

Memahami prinsip-prinsip utama desain antarmuka aplikasi yang intuitif, menarik, dan berpusat pada pengguna.

6. Projek Dasar PPLG

Mengintegrasikan semua pondasi ilmu ke dalam pembuatan aplikasi nyata sederhana dari awal.

FASE F (KELAS XI - XII)

Menguasai Keahlian, Membangun Solusi Nyata

1. Pemrograman Lanjut

Menerapkan paradigma Object-Oriented Programming (OOP) dan struktur data kompleks pada aplikasi.

2. Pemrograman Web

Membangun platform web dinamis, responsif, berkecepatan tinggi, dan terhubung dengan peladen database.

3. Pemrograman Mobile

Mengembangkan aplikasi mobile native maupun cross-platform yang kaya fitur untuk perangkat Android.

4. Basis Data Lanjut

Merancang arsitektur database berskala besar, optimasi index query, dan manajemen penyimpanan modern.

5. Rekayasa Perangkat Lunak

Menganalisis kebutuhan sistem perangkat lunak, penyusunan dokumentasi teknis, serta implementasi siklus hidup SDLC.

6. UI/UX Design

Merancang pengalaman digital komprehensif, riset alur user, hingga pembuatan high-fidelity interactive prototype.

Fasilitas & Pendukung Pembelajaran

1. Sarana & Hardware

Akses spesifikasi perangkat workstation tangguh serta lingkungan lab berteknologi tinggi yang nyaman.

2. Teaching Factory (TEFA)

Simulasi alur kerja profesional industri dengan mengerjakan langsung proyek software nyata milik klien bisnis.

3. Kerja Sama DUDI

Program kurikulum khusus yang diselaraskan langsung oleh industri teknologi terkemuka dan startup nasional.
