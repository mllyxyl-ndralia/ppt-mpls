Profesi Rekayasa Perangkat Lunak

Pelajari 4 pilar utama dalam membangun aplikasi modern

Frontend Development

Fokus pada apa yang dilihat dan berinteraksi langsung dengan pengguna (Client-Side).

Teknologi Inti

  • HTML: Struktur dasar halaman web.
  • CSS: Desain, tata letak, dan visual.
  • JavaScript: Logika dan interaktivitas website.

Framework Populer

  • React.js (Komponen & State)
  • Vue.js (Mudah dipelajari)
  • Angular (Skala Enterprise)

Backend Development

Mengelola logika di balik layar, database, server, dan API (Server-Side).

Bahasa & Framework

  • Node.js: JavaScript di sisi server (Express.js).
  • Python: Django dan Flask.
  • PHP: Laravel (Sangat populer di Indonesia).

Database & API

  • Relational: MySQL, PostgreSQL.
  • Non-Relational: MongoDB, Redis.
  • Arsitektur REST API & GraphQL.

Mobile Development

Pembuatan aplikasi khusus untuk perangkat genggam seperti smartphone dan tablet.

Native Development

  • Android: Menggunakan Kotlin atau Java dengan Android Studio.
  • iOS: Menggunakan Swift dengan Xcode.

Cross-Platform

  • Flutter: Menggunakan bahasa Dart (Satu kode untuk iOS/Android).
  • React Native: Berbasis JavaScript/React.

Desktop Development

Pengembangan aplikasi komputer yang berjalan langsung di sistem operasi Windows, macOS, atau Linux.

Teknologi Native

  • C# / .NET: Standar utama untuk aplikasi Windows (WPF/WinForms).
  • Swift / Objective-C: Untuk aplikasi native macOS.
  • C++: Untuk performa tinggi (game, software editing).

Teknologi Hybrid & Modern

  • Electron: Membuat aplikasi desktop pakai HTML/CSS/JS (Contoh: VS Code, Discord).
  • JavaFX: Aplikasi desktop lintas platform berbasis Java.
